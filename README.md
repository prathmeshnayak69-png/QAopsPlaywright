# Playwright Automation Framework

## Tech Stack
- Playwright
- JavaScript
- Node.js
- Page Object Model (POM)
- Git & GitHub

## Features
- End-to-End Automation
- Page Object Model
- Data-Driven Testing
- Environment Variables
- Secure Credential Management
- Screenshots & Videos
- Trace Viewer
- HTML Reports

## Project Structure
- tests/
- pageobjects/
- utils/
- playwright.config.js

## Installation
npm install

## Run Tests
npx playwright test

## Run in Headed Mode
npx playwright test --headed

## Generate Report
npx playwright show-report
